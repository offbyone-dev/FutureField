# AI Tools and Development Disclosure

This document summarizes the tools used to research, design, and develop
**FutureField**.

## Frontend Development

-   **ChatGPT:** Used for research, coding support, debugging, and
    improving React/TypeScript components.
-   **Claude:** Used for technical research, code assistance, and
    debugging.
-   **Figma:** Used to design and refine the user interface and visual
    layouts.

## Backend Development and AI Integration

-   **ChatGPT and Claude:** Used for research, system planning,
    algorithm discussions, coding support, and documentation.
-   **Google Antigravity:** Used to assist frontend/backend
    implementation, API integration, and code refinement.
-   **Google Gemini API:** Powers the in-app **Ask FutureField**
    assistant, which uses the user's question, field context, and recent conversation history to provide agronomic guidance.
